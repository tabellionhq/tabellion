# APR-0001: Free and open

- Status: Accepted
- Date: 2026-10-14

## Principle

Everyone loves to progress, nobody likes being monitored. The system must be as free as possible: as a developer, I can credit up my skills, and always look for a better job.

We can't promise it will be confidential, but the data has to be open.

Open means the developer owns and can export everything. The "skills evaluation" schema itself has to be open, so other systems can use it.
