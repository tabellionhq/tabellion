# APR-0003: Skills curriculum standard, existing standards for the rest

- Status: Accepted
- Date: 2026-10-18

## Principle

We want to promote an interoperable open model for exchange.

We provide the skills curriculum standard, and defer to other communication standards and protocols when available, be it for data or exchange.

## What we define

What no standard covers: a person's practice of a skill, on a concept, at an occupation, over a period, at a level; and the views a person shares.

## What we adopt

| Need | Standard |
|---|---|
| Skills, occupations | ESCO ([ADR-0003](../adr/ADR-0003-professional-skills-referential.md)) |
| Concepts | Wikidata ([ADR-0001](../adr/ADR-0001-describe-concepts-with-wikidata.md)) |
| Identities | vCard |
| Dates, periods, time zones | ISO 8601, iCalendar |
| Access | bearer tokens, OpenID Connect |
| CV exports | Europass, HR Open Standards, JSON Resume (as adapters) |

## What inspires us

| Pattern | Source |
|---|---|
| A stream of updates that makes catching up easy | RSS, Atom |
| Versioned publications | OCI (Open Container Initiative) |
| Raw, time-stamped data; consumers store and search at scale | OpenTelemetry |
