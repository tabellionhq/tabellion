# Functions

- Status: Draft

Functions the system provides, independent of technology. Each is traced to the user stories that require it. Functions are added as stories are analysed.

| ID | Function | In | Out | Stories |
|---|---|---|---|---|
| F01 | Extract statements from a document | document | statements (occupation, period, terms), each with its excerpt | US-01 |
| F02 | Resolve a term to identifiers | term, kind (skill, occupation, concept, context) | candidates (ESCO, Wikidata) with confidence | US-01, US-02 |
| F03 | Propose facts to a record | person, facts, evidence | facts with status proposed | US-01 |
