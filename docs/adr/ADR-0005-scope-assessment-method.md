# ADR-0005: Scope is the assessment method

- Status: Accepted
- Date: 2026-10-15
- Drafted by: owner

## Context

What a CV line shows (ESCO skill, Wikidata context, level).

## Decision

We work on an assessment method. What people want to do with it is out of scope: it could be producing a minimal PDF, showing a complete and detailed web page, etc.

What we have to determine is the interfaces and the data model, not the implementations.

## Reason

Same problem as ADR-0004.
